# Diabetes Prediction Web App (Symptoms Based)
### Flask + Machine Learning

A Machine Learning–powered **Flask Web Application** that predicts whether a person is likely to have **Diabetes** based on symptoms provided by the user.

---

##  Project Overview

This system uses a **symptom-based approach** to predict diabetes.  
Users enter basic symptoms through a web interface, and the trained ML model provides an instant prediction.

### Symptoms Considered

- Excessive thirst  
- Frequent urination  
- Fatigue  
- Sudden weight loss  
- Blurred vision  
- Increased hunger  
- Slow healing wounds    

### Prediction Output

- **Likely Diabetic**
- **Not Diabetic**

---

##  Machine Learning Model

- **Algorithm:** Random Forest Classifier  
- **Approach:** Symptom-based classification  
- **Training:** Labeled dataset with diabetes outcomes  
- **Deployment:** Model integrated with Flask for real-time prediction  

---

##  Technologies Used

- Python  
- Flask  
- HTML, CSS  
- Pandas  
- NumPy  
- Scikit-learn  

---

##  Application Workflow

1. User enters symptoms in the web form  
2. Input data is processed and sent to the ML model  
3. The trained model predicts the result  
4. Prediction is displayed on the web page
